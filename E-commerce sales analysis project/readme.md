# E-Commerce Sales Analysis

An end-to-end e-commerce sales analysis project using Excel, Python, Pandas, NumPy, Microsoft SQL Server, and Power BI.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Python
- Pandas
- NumPy
- Microsoft SQL Server
- Power BI

## 📊 Project Objective

The goal of this project is to analyze e-commerce sales data and identify useful business insights related to sales, profit, customers, products, payment methods, and order status.

## 🔄 Project Workflow

Raw Data  
↓  
Excel  
↓  
Python + Pandas + NumPy  
↓  
Data Cleaning & Analysis  
↓  
Microsoft SQL Server  
↓  
SQL Analysis  
↓  
Power BI Dashboard

## 🔍 Analysis Performed

- Total orders
- Total sales
- Total profit
- Product performance
- Category performance
- Payment method distribution
- Cancelled orders
- Customer analysis
- Monthly sales trends
